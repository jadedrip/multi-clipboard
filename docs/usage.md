# 使用说明

多元剪贴板是一款剪贴板内容切分与拖拽工具。本文面向最终用户，介绍常见操作与配置。

## 基本流程

1. **复制内容**：在 Excel、文本编辑器、浏览器等应用中复制多行数据（支持换行、制表符、Excel 表格格式）
2. **自动切分**：程序自动捕获剪贴板内容并切分为独立条目
   - 内容为多行时自动弹出窗口展示条目
   - 内容为单行时在后台更新列表，不打扰当前操作
3. **粘贴条目**：
   - **拖拽**：从窗口拖拽条目到目标输入框，松开即完成粘贴
   - **双击**：双击条目复制到系统剪贴板，再到目标处粘贴
   - **右键 → 复制到剪贴板**：同上

## 窗口操作

| 操作 | 方式 |
| :--- | :--- |
| 显示 / 隐藏窗口 | 全局快捷键 `Ctrl+Shift+M`，或点击托盘图标 |
| 窗口置顶 / 取消置顶 | `Ctrl+Shift+T`，或托盘菜单"置顶" |
| 关闭窗口 | 点击窗口关闭按钮（隐藏到托盘，程序继续运行） |
| 彻底退出 | 托盘菜单 → 退出 |
| 清空所有条目 | `Ctrl+Shift+X` |
| 复制所有条目 | `Ctrl+Shift+C`（条目以换行拼接） |
| 纯文本粘贴 | `Ctrl+Shift+V`（先复制目标文本，再粘贴为纯文本） |

## 条目管理

- **持久化（复选框）**：勾选条目左侧复选框，该条目固定显示在列表顶部，不受新复制内容覆盖影响；取消勾选可移除固定
- **标记已使用 / 未使用**：右键条目 → 标记为已使用 / 未使用。已使用条目显示绿色对勾并置灰，双击条目默认自动标记为已使用（可在配置中关闭）
- **拖拽失败时的回退**：若目标应用不支持拖拽接收，程序自动回退为"复制到剪贴板 + 模拟点击 + 粘贴"

## 搜索过滤

- 条目数大于 1 时，窗口顶部自动出现搜索框
- 输入关键词实时过滤，匹配条目高亮、不匹配条目淡化
- 状态栏实时显示匹配数量；清空关键词恢复完整列表

## 主题切换

- 托盘菜单 → 切换主题，在亮色 / 暗色之间切换
- 默认主题可在 `config.json` 的 `ui.theme` 中修改

## 配置窗口

托盘菜单 → 配置，可设置：

- **快捷键**：为 5 个功能自定义全局快捷键（点击输入框后按下组合键）
- **自动弹出**：剪贴板变化时是否自动弹出窗口

修改后点击"确定"生效。

## 日志与故障排查

日志目录（Windows）：`%APPDATA%\MultiClipboard\logs`

| 文件 | 内容 |
| :--- | :--- |
| `multiclipboard.log` | 完整运行日志（5MB × 5 份轮转） |
| `error.log` | 错误级别日志 |
| `crash_*.log` | 崩溃报告 |

常见问题：

- **快捷键无效**：检查是否与其他软件冲突，可在配置窗口重新设置
- **拖拽无反应**：部分应用（如部分 Web 输入框）不支持拖拽，程序会自动回退模拟粘贴；若目标窗口为管理员权限运行，需以管理员身份运行本程序
- **剪贴板未捕获**：确认文件 / 图片复制内容不会被当作文本条目捕获（设计如此，仅捕获纯文本）
